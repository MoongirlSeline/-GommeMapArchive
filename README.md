# GommeMapArchive
Maps from the Minecraft server GommeHD.net for free download

1200 Maps

This is a project, aiming to archive all the server maps from all the Minecraft servers. Especially old and deleted maps, that might still hold some nostalgic value for players, are of great interest.

**PLEASE NOTE**: All the maps still belong to their original creators, so use them responsibly. Each map contains a file, called "Credits.txt", that stores the credits of the map (mostly Minecraft in-game names) if they are known. If not, you could ask staff members of the server the map originated from or search for heads or signs of the builders on the map.

If you have maps, questions, corrections or requests, you can contact me by adding "moongirlseline" on Discord. Every contribution is very valuable and all maps from all servers are gladly seen! 🙏 If you have Maps from other games similar to Minecraft, i would be glad to start another archive!
Also please feel free to download and store this archive locally, so the maps don't turn into lost media in the event of a potential takedown.

**Let's make this a community project!**
